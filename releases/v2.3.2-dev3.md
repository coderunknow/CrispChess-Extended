# CrispChess Extended v2.3.2-dev3 (prerelease)

This is a development prerelease, **not** the stable v2.3.2 release.

## Windows Frozenight runtime repair

The official `v2.3.2-dev2` Windows ZIP omitted `frozenight_ffi.dll`. On Windows,
the missing runtime produced loader error 126; Engine Lab then showed the
secondary message `Bad state: initialize returned with state error`. A controlled
experiment with the actual dev2 archive confirmed that adding only the locked
Frozenight DLL restored ordinary gameplay, all four Lab presets and Match.

dev3 builds and bundles the locked Frozenight runtime in the Windows release,
verifies every required x64 PE image, ABI-2 exports, app-local Visual C++ runtime
files and import closure, and tests the extracted ZIP before publication. The
Windows bundle manifest is published beside the ZIP as a permanent release asset.

## Initialization and Engine Lab integrity

- Typed startup diagnostics preserve the original cause, loader/native code,
  stage, platform, library path and symbol; failed initialization is never
  reported as ready.
- Frozenight ABI 2 isolates native engine instances; disposal is queued after
  searches. The WASM singleton is leased and serialized across Dart instances.
- Lab cancellation, deadline and unavailable pairings remain truthful partial
  results. Calibration anchors must match the measured engine identity, version
  and move budget. Opening suites, automatic caps, rating uncertainty and export
  safety are validated.

## Validation

Release assets are built and structurally verified by the release workflow.
Windows validation extracts the delivered ZIP, probes the real DLL through 200
create/search/destroy cycles, launches the delivered executable and checks that
Flutter and the Visual C++ runtime load from the extracted archive. Repository
CI, Engine Lab tests, native tests and cross-platform builds run against the
release source. See the PR and audit log for exact run IDs and limitations.

## Known limitations

- Windows CI is Windows Server 2025, not the owner's Windows 10 installation.
  Actual Windows 10 verification remains separate.
- Binary builds are source-reproducible but not claimed byte-for-byte
  reproducible across hosted MSVC/Rust toolchain installations.
- Smoke games are not rating calibration. No absolute Elo is advertised without
  a compatible declared anchor.
- The iOS IPA is unsigned. App Store/TestFlight submission and external signing
  are not part of this GitHub prerelease.
